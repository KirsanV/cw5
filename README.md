#  Habits Tracker

API для отслеживания привычек с интеграцией Telegram бота. Создавайте полезные привычки, получайте напоминания и мотивируйтесь публичными привычками других пользователей.

##  О проекте

Проект реализует систему трекинга привычек с возможностью:
- Создания и управления привычками
- Получения напоминаний через Telegram
- Просмотра публичных привычек других пользователей
- Валидации привычек по бизнес-правилам

## Возможности

###  Управление привычками
- Создание привычек с указанием действия, места, времени
- Настройка периодичности выполнения
- Указание вознаграждений или связанных приятных привычек
- Публикация привычек для общего доступа

###  Напоминания
- Интеграция с Telegram ботом
- Автоматические напоминания в указанное время
- Создание привычек через Telegram интерфейс

###  Социальные функции
- Просмотр публичных привычек других пользователей
- Мотивация через примеры успешных привычек

###  Безопасность
- JWT аутентификация
- Права доступа к личным данным
- CORS настройки для фронтенда

##  Технологии

- **Backend**: Django 4.2, Django REST Framework
- **База данных**: PostgreSQL
- **Аутентификация**: JWT (Simple JWT)
- **Очереди задач**: Celery, Redis
- **Документация**: Swagger/ReDoc (drf-yasg)
- **Тестирование**: pytest, coverage
- **Code quality**: Flake8
